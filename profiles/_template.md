# Profile Template

Uniform profile shape. Copy and fill. Keep keys stable.

- name: profile id, kebab-case.
- platform: Web | iOS | iPadOS | macOS | Android | Windows.
- container: lightest host rendering target.
- scope: animation | layout | appearance | logic (list).
- config ref: path to labconfig or saved profile JSON.
- schemaVersion: 1.
- build: DEBUG build id / tester gate.
- viewport: WxH + scale.
- appearance: light / dark / system + density.
- overrides: variant key-values applied on Save.
- notes: constraints, restore steps.
